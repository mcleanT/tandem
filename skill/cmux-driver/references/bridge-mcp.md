# Bridge MCP `tandem` — operator contract (tandem 0.1.0)

Started by Codex as `uv run --quiet --project <tandem repo> tandem-bridge` (stdio, FastMCP; the command `install.sh` prints for `codex mcp add tandem`). It wraps the cmux CLI through argument arrays only: no shell, no generic RPC, no pane deletion, no process cleanup. State (bindings, request records, task files, receipts) lives owner-only under `~/.local/state/tandem/` (override: `CMUX_BRIDGE_STATE_DIR`); it contains prompt text, so treat it as sensitive.

The server process must be able to open the cmux socket. If `bridge_discover` returns `transport.ok: false`, report `transport.requirement` verbatim and stop; do not broaden socket access yourself (the tandem repo's `scripts/cmux_access_plan.sh` is the operator's tool for password mode, with the secret in an owner-only file named by `CMUX_BRIDGE_PASSWORD_FILE`).

## Tools (nine)

| Tool | What it does |
|---|---|
| `bridge_discover(workspace_uuid?, max_targets≤50)` | Diagnose socket access; list Claude targets `{workspace_uuid, surface_uuid, pid, alive, claude_session_id, cwd, model}`. |
| `bridge_bind(workspace_uuid, surface_uuid, claude_session_id, claude_pid, worktree_realpath, controller_id, role=writer\|monitor, lease_ttl_s=1800, purpose=implementation\|planning, expected_model=None)` | Bind by full identity and take a lease. Writer requires an agent hook event linking session, pid and cwd (else `bind_evidence_missing`; a monitor bind is an explicit, observe-only alternative). Writer leases are exclusive per surface and per worktree and last `lease_ttl_s` (default 1800, clamped 60..86400; no tool renews them). A new writer bind by the same `controller_id` supersedes that controller's other live writer bindings (released and marked superseded, every lease still naming them dropped, ids returned in `superseded_bindings`; submit/compact on them return `lease_lost`, observe/wait return `released`); a same-surface rebind also carries over `paused` from the most recent writer binding on that surface, even if it was released or its lease expired. `controller_id` must be a non-empty, non-whitespace string (max 200 chars) else `bad_request`. Worktree identity is the case-insensitive-canonical on-disk path, so a differently-cased spelling of the same directory hits the same lease. A different controller gets `lease_conflict`. Applies the model gate. Returns `binding_id`, `revision` (starts at 1), `boot_id`, `cursor_seq`. |
| `bridge_observe(binding_id, controller_id, lines=30, max_events=200, after_seq=None)` | Screen state (`prompt_idle`, `staged`, `running`, `modal`, `not_claude`, `unknown`), `ctx_used_pct`, events after your cursor, `paused`, and `next_after_seq` to pass back. Mutates nothing. |
| `bridge_submit(binding_id, controller_id, request_id, text, expected_revision, kind=task\|reply\|steer, accept_timeout_s=12)` | Stage literal text and press Enter at most once. Single-line short text goes inline; multi-line or long text (max 16000 chars) is written to an immutable 0444 task file and a short `Task brief: <path>` line is delivered. Same `request_id` replays a terminal receipt or reconciles a non-terminal one. Lease and pause are re-checked under one lock hold right before Enter; a pause after staging raises `paused` with the payload staged and no Enter (resume, re-call with the SAME `request_id`). Refuses stale revision, busy/unknown/non-Claude surface, monitor or superseded/released binding, `paused`, model-gate codes. `steer` queues one single-line payload into a running turn and is for explicit, scoped use only. |
| `bridge_wait(binding_id, controller_id, until, timeout_s=25, request_id=None, evidence=None, after_seq=None)` | `until`: `accepted`, `turn_complete`, `idle`, `task_complete`, `compaction_complete`. Sends nothing. Outcomes: `satisfied`, `timeout`, `reconnect_gap`, `identity_lost`, `blocked_modal`. Non-terminal results mean call again. `task_complete` requires `request_id` and `evidence` (`{"file", "contains"}` or `{"file", "sha256"}`) including a current `drained_attestation`; file existence alone is never evidence. |
| `bridge_compact(binding_id, controller_id, request_id, expected_revision, checkpoint, ctx_used_pct=None, reason=None, drained_attestation=None, force=False, timeout_s=120)` | Compact at 30% used, before 40%. Needs a fresh drained-checkpoint artifact (same evidence shape; `force` never bypasses it) AND a `drained_attestation` `{"drained": true, "attested_by": <controller_id>, "evidence": <text>}`. Outcomes: `not_due`, `deferred` (needs `reason`), `needs_drained_attestation`, `completed`, `uncertain` (nothing resent). Same pre-Enter lease/pause re-check; after a pause, resume, clear the staged `/compact`, and call again with a NEW `request_id`. |
| `bridge_pause(binding_id, controller_id, reason)` | Pause (reason ≤500 chars). Submit and compact refuse with `paused`; a pause landing before Enter withholds it and leaves the payload staged. Observe/wait keep working. Owner only (`not_owner` otherwise). |
| `bridge_resume(binding_id, controller_id)` | Clear the pause. Owner only. |
| `bridge_release(binding_id, controller_id)` | Owner only (`not_owner` otherwise). Drop the lease and delete the binding's task files (unless a request is still in flight); never closes the surface or the process. Makes the binding unusable (`released`); does NOT clear a pause. |

## Delivery states

transport (`send` OK) < staged (text in the editor) < **accepted** (the session transcript has a user message whose sha256 equals the delivered line's, at/after the send) < running < turn_complete (Stop after the accepted message, or `turn_duration`) < task_complete (Claude's own evidence file, written after acceptance, plus drained attestation). `UserPromptSubmit` events are corroboration only. The receipt has two hashes: `text_sha256` (the brief) and `delivered_text_sha256` (the line actually staged); for task files they differ.

## Refusal codes

Refusals arrive as ToolErrors prefixed `<code>:`.

- Request and identity: `bad_request`, `identity`, `identity_lost`, `bind_evidence_missing`, `not_claude`, `not_writer`, `unknown_binding`, `unknown_request`, `request_conflict`, `stale_revision`, `busy`, `unknown_state`.
- Lease: `lease_conflict` (another controller holds the writer lease at bind), `lease_expired` (TTL lapsed; rebind the SAME session with the SAME `controller_id`), `lease_lost` (superseded, or lease no longer held), `released`.
- Ownership and pause: `not_owner` (any binding tool called with a `controller_id` other than the one the binding was bound with; nothing is read, sent or changed), `paused`.
- Delivery: `staged_unverified`, `uncertain_foreign`, `checkpoint_required`, `checkpoint_stale`, `deferral_needs_reason`.
- Send path (`send` stages text only; Enter is a separate keystroke that is pressed only after the staged line is verified as exactly this request's, so none of these codes means Enter was pressed by that call):
  - `send_response_lost` (the send ran, its reply was lost) and `send_failed` (the send command exited non-zero or timed out; the effect may still have applied): text MAY be staged. Never resend and never mint a new `request_id`. Call again with the SAME `request_id`: the bridge correlates the transcript first, then, only if the editor holds exactly this line, presses Enter once. Otherwise it returns `staged_unverified`.
  - `pre_enter_gate_error` (the pre-Enter gate raised unexpectedly; unreachable from the MCP tools, which pass no gate) and `paused` after staging: payload is staged, Enter NOT pressed, request marked `uncertain`. Fix the cause (resume if paused), then retry the SAME `request_id` to reconcile.
  - `send_not_attempted` (only a simulated pre-send fault in tests; real CLI failures are `send_failed`): zero bytes were sent. Retrying the SAME `request_id` re-sends the delivered line (the only resend basis); nothing can be staged or pressed yet.
  - **These same-`request_id` rules apply to `bridge_submit` only.** For `bridge_compact`, a retry with the same `request_id` only re-checks the transcript for a compact boundary; it never resends and never presses Enter. After any compact send-path refusal or a post-staging `paused`, clear the staged `/compact` from the prompt box (inspect with `bridge_observe`), then call `bridge_compact` with a NEW `request_id`.
  - `bad_delivery`: internal guard, a multi-line payload reached the inline send (submit converts multi-line to a task-file reference first, so this indicates a bridge bug). Nothing was sent or pressed. Do not retry the same input expecting a different result; report it. Fix input only for `bad_request`/`stale_revision` style refusals, which are raised before anything is staged.
  - Same rules for `bridge_compact` (`/compact` is the staged line), except after a pause: clear the staged `/compact` and use a NEW `request_id`.
- Model gate: `model_policy` and `planning_session` (planning-only family for implementation), `model_required` (planning purpose, no model named), `model_unknown` (no known family; see `TANDEM_ALLOW_UNKNOWN_MODEL`), `model_unverified`, `model_mismatch`, `model_changed`, `model_policy_config` (malformed `TANDEM_PLANNING_ONLY_MODELS` or `TANDEM_ALLOW_UNKNOWN_MODEL`; fails closed).
- `no_terminal_view`: the surface has no terminal view (created unfocused; `read-screen` fails with `Failed to read terminal text`). Raised by bind/submit/wait paths before anything is sent; `bridge_observe` returns `state: unknown` with `error_kind: no_terminal_view` and the instruction. Select its workspace once (`cmux select-workspace`) or relaunch via `executor_session.py launch`, then retry. Not a transport fault; no resend.
- `busy` with an `instruction` about a prompt suggestion (also on `bridge_observe` when `state` is `staged`): the binding's `prompt_suggestions` is not `disabled` and the editor shows text with no request of ours in flight, which may be Claude Code's ghost-text prompt suggestion. Launch via `executor_session.py` (sets `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false`) or set `promptSuggestionEnabled: false`, then re-bind. The bridge never clears the editor. `bridge_bind` reports `prompt_suggestions: disabled|enabled_or_unknown`.
- Transport: `transport_<kind>` (`access_denied | socket_missing | connection_refused | not_found | internal_error | timeout`).
